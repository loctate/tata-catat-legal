# Privacy Policy for Tata Catat

**Last updated: August 15, 2026**

Tata Catat is a simple personal finance recording application developed to help users record income and expenses in an organized way.

This Privacy Policy explains how Tata Catat handles information when you use the application.

## 1. Information We Collect

Tata Catat does not require users to create an account or sign in.

The application does not collect personal information through a remote server.

Financial records entered by users, such as:

- income amounts,
- expense amounts,
- income sources,
- expense categories,
- transaction dates, and
- optional notes,

are stored locally on the user's device.

## 2. Local Data Storage

Transaction data and category settings are stored locally on the device using the application's local database.

Tata Catat does not automatically upload transaction data to a remote server or cloud service.

If the application is uninstalled or application data is cleared, locally stored data may be permanently deleted unless the user has previously exported or backed up the data.

## 3. Exporting Data

Tata Catat provides features that allow users to export transaction information to CSV and PDF files.

Exporting data is initiated manually by the user.

When a user chooses to share or save an exported file, the file may be handled by other applications or services selected by the user, such as file managers, messaging applications, email applications, or cloud storage services.

Tata Catat does not control how those external applications or services process exported files.

## 4. Internet and Third-Party Services

The core financial recording features of Tata Catat are designed to work locally on the user's device.

Tata Catat does not use advertising services, analytics services, social login, or financial service providers as part of its core functionality.

The operating system or device may provide system-level services required to install, run, print, save, or share files.

## 5. Data Sharing

Tata Catat does not sell, rent, or trade user transaction data.

Tata Catat does not intentionally transmit locally stored financial records to the developer.

Users control whether exported files are shared with third parties.

## 6. Data Security

Because financial records are stored locally on the user's device, users are responsible for maintaining the security of their device.

Users are encouraged to use device security features such as screen locks, PINs, passwords, or biometric protection where available.

## 7. Children's Privacy

Tata Catat is not specifically designed for children.

The application does not knowingly collect personal information from children through a remote server.

## 8. Data Deletion

Users can delete individual transactions and categories from within the application where supported.

Users may also remove locally stored application data by uninstalling Tata Catat or clearing the application's storage through Android device settings.

## 9. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes in the application, applicable requirements, or privacy practices.

Any updated version will be published on this page with a revised "Last updated" date.
